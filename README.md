# MindMap 마인드맵

노드와 연결선으로 생각과 설비 흐름을 정리하는 웹 앱입니다. PC·휴대폰·태블릿에서 사용할 수 있습니다.

앱 실행: https://dfg2fg42.github.io/MindMap/

## 선 중간에서 노드로 연결

**🔗 연결 아이콘 → 출발 노드 → 기존 선의 원하는 지점** 순서로 노드에서 선 중간에 연결할 수 있습니다. 직선·곡선·공통선·참조선을 지원하며 원래 선과 노드 위치를 유지합니다. 포트 점을 누르면 출발 면도 지정합니다. 새 선의 **정방향 →** 화살표는 출발 노드에서 선 중간 접점으로 향합니다. 기존 노드 간 연결도 유지합니다.

연결 아이콘은 새 연결을 만드는 모드로 작동합니다. 기존 선의 연결면 변경은 선 설정창의 **연결점 포트 수정**에서 사용할 수 있습니다.

기존 선에서 연결하고 싶은 지점을 클릭합니다. 태블릿은 선을 누릅니다. 선 설정창의 **┬ 이 지점에서 노드 연결**을 선택한 뒤 대상 노드를 누르면 예시처럼 T자 연결선을 만듭니다. 기존 선과 노드 위치·부모 관계를 유지하며 새 분기선만 추가합니다.

접점의 작은 원을 원래 선을 따라 끌어 위치를 조절합니다. 노드 이동·선 모양 변경·확대·축소 후에도 접점이 선을 따라갑니다. 새 선의 화살표·색상·점선·곡선 설정은 기존 선 설정창에서 변경할 수 있습니다. 연결 대기 중에는 안내의 **취소**, 빈 화면 클릭 또는 **Esc**로 취소합니다.

일반 연결선과 참조선에 사용할 수 있으며 분기선에서 다시 분기할 수도 있습니다. 자동 저장·되돌리기·JSON 및 HTML 백업을 지원합니다. 원래 선을 삭제하면 붙어 있던 분기선도 제거하지만 대상 노드들은 유지합니다. 카테고리 복사 시 원래 선의 양 끝 노드까지 포함하면 접점 연결도 함께 복사합니다.

## 원형 손잡이 숨기기

원을 클릭하거나 터치한 뒤 **원형 손잡이 숨기기**를 선택하면 연결선과 노드는 유지하고 조절 원만 숨깁니다. PC는 원 선택 후 **Delete / Backspace**로도 숨길 수 있습니다. 선을 선택해 **원형 손잡이 다시 표시**로 복원합니다. 일반 선·공통선·T자 접점을 지원하며 설정은 저장·되돌리기·백업에도 유지됩니다. 손잡이를 숨긴 공통선에 새 가지를 추가해도 숨김 상태를 유지합니다.

## 겹친 선과 화살표 분리

같은 노드로 들어오는 선들이 겹치면 그 선 중 하나를 클릭/터치하고 **접점 이동 → 도착점 → ↕ 겹친 접점 나누기**를 사용합니다. 좌우 면은 위·아래로, 위아래 면은 좌·우로 접점과 마지막 선 구간을 나눕니다. 출발점의 겹침은 **출발점**을 선택해 나눕니다. 노드 위치·연결 관계·그룹과 다른 선의 경로를 유지하고 공통 분기선도 지원합니다. 변경은 저장·되돌리기·백업에 유지됩니다.

## 그룹 수정과 분기선

노드가 여러 공통선에 연결되어 있으면 **＋ 분기선에 노드 추가**에서 추가할 대상을 선택합니다. `#1 AS-MV-20`처럼 상위 분기선의 자식이면서 HDR 분기선의 부모인 노드에서는 **20barg HDR**을 선택하면 HDR 열에 추가됩니다. 그룹 이름·분기선 방향·연결된 노드 수를 확인할 수 있습니다. 원하는 선 자체의 설정창에서 **＋ 이 분기선에 노드 추가**를 선택해도 됩니다. 기존 노드·선 위치를 유지하며, 일반 **하위 노드 추가**는 해당 노드에서 뻗는 분기선만 대상으로 합니다.

- **그룹 제목 → 노드 수정**: 검색 목록에서 노드를 체크해 기존 그룹에 추가하거나 제외합니다. 노드는 삭제하지 않으며 위치와 그룹 색상을 유지합니다. 그룹 제목을 끌면 추가된 노드도 함께 움직이고 제외한 노드는 남습니다. 되돌리기·불러오기 후에도 현재 구성원을 기준으로 이동합니다.
- **CBP 메뉴 → ┬ 하위 노드만 분기선 정리 (위치 유지)**: CBP에서 내려온 한 줄이 가로 공통선으로 갈라져 LP Heater A/B 위로 연결되는 모양을 만듭니다. CBP 우측 등 별도의 참조선은 포함하지 않습니다. 노드의 정렬과 부모·자식 관계, 기존 색상·화살표 방향을 유지합니다. A/B만 다중 선택하면 **선택한 2개 노드만 분기선 정리**로 표시하며 해당 선만 정리합니다. 선 설정창의 **분기선 정리**도 같은 선택 범위를 따릅니다. 공통선의 원을 위아래로 끌어 높이를 조절할 수 있습니다.
- **부모 또는 자식 노드 메뉴 → ＋ 분기선에 노드 추가**: 같은 공통선에 C 등 새 노드를 추가합니다. 가로 공통선은 같은 줄의 빈 곳에 배치하고, 세로 공통선은 같은 열의 맨 아래에 추가합니다. 기존 노드와 다른 선의 위치는 유지합니다. 부모에서 일반 **하위 노드 추가**를 눌러도 기존 분기선에 연결합니다. 부모 양쪽에 가지가 있으면 원하는 쪽의 기존 노드 메뉴에서 추가합니다.

세 작업은 자동 저장과 되돌리기를 지원합니다. 그룹의 구성을 바꾸면 테두리를 포함된 노드에 맞춰 다시 계산합니다.

분기선으로 정리할 부모·자식 사이에는 세로 간격이 필요합니다. 다른 색이나 점선 설정은 그대로 유지하므로, 통일된 색상·실선은 기존 선 설정에서 선택합니다. 새 노드를 그룹에도 넣으려면 **그룹 → 노드 수정**에서 체크합니다.

세로 공통선에 추가한 노드는 기본적으로 기존 가지의 색상과 선 스타일을 따릅니다. 노란색으로 구분하려면 새 노드를 선택해 색상을 바꿉니다. 아래쪽에 다른 노드가 있거나 이름이 긴 경우 새 노드만 이동해 겹침을 피하고 기존 공통선 위치를 유지합니다.

PC는 Ctrl을 누른 채 A/B를 클릭하고, 태블릿은 **다중 선택**을 켠 뒤 A/B를 눌러 선택합니다. 이전 버전에서 다른 선까지 바뀐 경우 되돌리기 이력이 있으면 먼저 **Ctrl+Z / 되돌리기**로 복원한 뒤 원하는 노드만 선택해 정리합니다.

## PWA 설치 기능

- 홈 화면에 앱으로 설치하고 주소창 없이 실행할 수 있도록 `standalone` 표시를 설정했습니다.
- 앱 시작 주소와 설치 범위는 기존 배포 주소의 `/MindMap/`입니다.
- 마인드맵 모양의 192×192·512×512 앱 아이콘을 추가했습니다.
- 서비스 워커는 네트워크 요청을 그대로 전달합니다. 별도의 앱 캐시를 만들거나 기존 저장 데이터를 삭제하지 않습니다.
- 기존 디자인, 노드·메모 저장, 이미지 저장, HTML 백업, PC 조작과 태블릿 펜 선택 기능을 유지했습니다.

## 휴대폰·태블릿에서 설치

삼성 인터넷에서는 앱 주소를 연 뒤 메뉴의 **홈 화면에 추가** 또는 **앱 설치**를 선택합니다. Chrome에서는 **⋮ → 설치 및 바로가기 만들기 → 설치**를 선택합니다. 메뉴 이름은 브라우저 버전에 따라 다를 수 있습니다.

설치 후 **홈 화면의 MindMap 아이콘**을 눌러 실행하면 브라우저 주소창 없이 열립니다. 일반 브라우저 탭에서 주소를 열면 주소창이 표시됩니다. 안드로이드 상태 표시줄과 내비게이션 바는 남을 수 있습니다.

## 데이터 저장과 인터넷 연결

기존과 동일하게 현재 브라우저에 데이터를 저장합니다. 삼성 인터넷과 Chrome의 저장 공간은 별도이므로 브라우저 사이에서 자동으로 공유되지 않습니다. 브라우저를 바꿀 때는 기존 백업·불러오기 기능을 사용합니다.

이번 구성에는 별도 오프라인 캐시를 넣지 않았으므로 앱을 새로 실행할 때 인터넷 연결이 필요합니다. 이미 열린 앱의 편집과 로컬 저장은 기존대로 작동합니다.

## 배포 파일

```text
index.html
manifest.json
sw.js
icons/icon-192.png
icons/icon-512.png
```

앱을 배포할 때는 위 파일을 모두 유지합니다. 다른 저장소 경로로 옮기면 manifest의 `id`, `start_url`, `scope`도 수정합니다.

## 확인한 항목

Chrome 설치 조건과 manifest 파싱, 서비스 워커 활성화 및 범위, 기존 노드·메모·이미지 보존, 저장 후 새로고침, HTML 백업, PC 조작, 태블릿 펜 다중 선택과 하단 도구 접기 검사를 통과했습니다. 삼성 인터넷의 실제 설치 화면은 기기에서 확인해야 합니다.
