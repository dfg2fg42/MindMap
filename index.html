📁 다른 카테고리로 복사 / 이동

메모·이미지와 포함된 노드 사이의 연결을 유지합니다. 대상 캔버스의 오른쪽 빈 공간에 배치됩니다.

❓ 기능 안내 & 사용법

처음이라면 「처음 시작하기」를, 폰·태블릿에서는 「휴대폰·태블릿 조작」을 먼저 확인하세요. 기능 이름을 누르면 해당 설명으로 이동합니다. 각 제목을 눌러 설명을 펼치거나 접을 수 있습니다.

휴대폰·태블릿처음 시작하기 카테고리 노드 여러 노드 선택·이동·정렬 연결선 그룹 메모·체크리스트·이미지 다른 카테고리로 복사·이동 화면 보기·구슬·잠금·검색 저장·백업·복원·초기화 자주 쓰는 단축키 한눈에 보기
휴대폰·태블릿 조작 7개 항목
화면 이동·확대빈 공간을 한 손가락으로 끌어 이동하고, 두 손가락을 벌리거나 오므려 확대·축소합니다. 잠긴 노드 위에서도 화면을 이동할 수 있습니다.
노드 선택·이동노드를 한 번 누르면 선택합니다. 잠금이 꺼져 있으면 노드를 끌어 위치를 바꿀 수 있습니다.
이름·메모·삭제노드를 길게 누르거나 선택 후 아래의 「노드 메뉴」를 누르세요. 두 번 누르면 이름을 편집합니다. 메뉴의 「노드 설정」에서 색상·크기·글자 모양을 바꿉니다.
여러 노드 선택아래의 「다중 선택」을 켠 뒤 노드를 눌러 선택·해제합니다. 선택된 노드를 끌면 함께 이동합니다. 위쪽 「그룹」으로 묶거나 메뉴에서 함께 삭제할 수 있습니다.
카테고리·검색·상단 도구「카테고리」로 목록을 열고, 연필 버튼으로 이름을 바꿉니다. 「검색」으로 노드를 찾습니다. 상단 도구는 좌우로 밀면 나머지 버튼을 볼 수 있습니다.
새 노드·되돌리기아래의 「새 노드」는 화면 중앙에 독립 노드를 만듭니다. 「되돌리기」로 이동·이름 변경·삭제 등 지원 작업을 복구하고 「선택 해제」로 선택을 지웁니다.
모바일 메모와 저장메모창에서 입력한 내용은 자동 저장됩니다. 「닫기」로 지도로 돌아갑니다. 저장 데이터는 기기별로 다르므로 PC에서 옮길 때는 JSON 백업·불러오기를 사용하세요.
처음 시작하기 5개 항목
1. 작업할 카테고리 선택화면 왼쪽 가장자리에 마우스를 대고, 기존 카테고리를 클릭하거나 「＋ 새 카테고리」를 누르세요. 카테고리마다 별도의 지도가 있습니다.
2. 노드 만들기중심 주제를 클릭 → F2로 이름 입력 → Enter로 완료 → Tab으로 하위 노드를 추가하세요. 노드는 설비·주제 등을 적는 상자입니다.
3. 모양과 위치 바꾸기노드를 드래그해 옮기세요. 노드 더블클릭으로 크기·색상·글자 설정을 열 수 있습니다.
4. 연결하고 묶기「🔗 연결」로 관계를 추가하세요. 여러 노드는 빈 공간에서 Shift를 누른 채 드래그해 선택한 뒤 「📦 그룹」으로 묶으세요.
5. 작업 보관하기일반 작업 파일은 현재 브라우저에 자동 저장됩니다. 다른 PC로 옮기거나 별도로 보관하려면 「💾 백업」으로 내보내세요.
카테고리: 지도를 나누어 관리 6개 항목
왼쪽 가장자리 / 핸들가장자리에 마우스를 대면 목록이 열립니다. 핸들을 클릭하면 고정하거나 고정을 해제합니다.
＋ 새 카테고리 / 목록의 ＋상단 버튼은 새 카테고리, 목록 옆의 ＋는 해당 카테고리 아래에 하위 카테고리를 만듭니다.
카테고리 클릭 / 더블클릭클릭하면 해당 지도로 전환합니다. 이름을 더블클릭하면 이름을 바꿀 수 있습니다.
아이콘 / 펼침 화살표아이콘을 클릭하면 아이콘을 바꿉니다. 펼침 화살표로 하위 카테고리 목록을 접거나 펼칩니다.
카테고리 드래그목록의 다른 위치로 옮겨 순서를 바꾸거나 다른 카테고리 아래로 넣을 수 있습니다.
목록의 ×해당 카테고리와 하위 카테고리를 삭제합니다. 마지막 카테고리는 삭제할 수 없습니다.
노드: 생성·이름·모양 편집 10개 항목
노드 클릭 / 더블클릭클릭은 선택, 더블클릭은 설정 패널 열기입니다. 텍스트 편집은 F2 또는 우클릭 → 「텍스트 편집」입니다.
Tab / ＋ 하위 노드선택한 노드 아래에 연결된 새 노드를 만듭니다.
Enter / ＋ 같은 단계 노드선택한 노드와 같은 부모를 가진 노드를 만듭니다. 부모가 없는 독립 노드에서는 사용할 수 없습니다.
빈 공간 우클릭「독립 노드 생성」으로 부모에 연결되지 않은 새 노드를 만듭니다.
이름 편집 중Enter로 완료, Alt+Enter로 줄바꿈, Esc로 변경 취소입니다. 다른 곳을 클릭해도 편집이 완료됩니다.
설정 패널 − / ＋노드 상자 전체의 크기를 줄이거나 키웁니다.
설정 패널 🎨 / ›🎨로 노드 배경색을 고릅니다. 팔레트의 ＋로 사용자 색상을 추가할 수 있습니다. ›는 글자 설정을 펼치거나 접습니다.
글자색 / 자동노드를 더블클릭하고 기본 설정의 「글자색」에서 원하는 색을 고르세요. 선택하는 동안 실시간으로 반영됩니다. 「자동」을 누르면 배경 밝기에 맞춰 글자색을 선택합니다. 흰색 배경에는 어두운 글자가 표시됩니다. Ctrl+Z로 되돌릴 수 있습니다.
B / U / a− / A+B는 굵게, U는 밑줄입니다. a− / A+는 글자 크기를 변경합니다.
S / 중요 표시선택한 노드에 별 표시를 추가하거나 해제합니다.
Delete / Backspace삭제 방식을 선택합니다. 연결을 끊고 선택 노드만 삭제하거나, 연결을 이어서 선택 노드만 삭제하거나, 하위 노드까지 함께 삭제할 수 있습니다. Ctrl+Z로 복구합니다.
여러 노드 선택·이동·정렬 8개 항목
빈 공간에서 Shift+드래그사각형 영역 안의 노드를 여러 개 선택합니다. 선택된 노드를 드래그하면 함께 이동합니다.
노드 드래그 중 Shift연결된 노드와 가로·세로로 맞추는 안내선이 나타나며 가까운 위치에 맞춰집니다.
Alt+↑ / Alt+↓같은 단계의 노드 순서와 위·아래 위치를 바꿉니다.
여러 노드 선택 → ⟳ 정렬2개 이상 선택한 뒤 「정렬」을 누르고 가로 또는 세로 정렬을 고르세요. 간격 입력으로 노드 사이 여백을 조절합니다.
그룹 선택 → ⟳ 정렬선택한 그룹에 노드가 2개 이상 있으면 그룹 안의 노드를 가로·세로로 정렬할 수 있습니다.
선택 없이 ⟳ 정렬현재 지도 전체를 자동 배치합니다. 직접 맞춘 위치가 달라질 수 있으므로 확인창을 읽고 실행하세요.
빈 공간 클릭 / Esc여러 노드 선택을 해제합니다. Esc는 현재 선택이나 연결 모드를 종료할 때도 사용합니다.
우클릭의 묶기 메뉴선택 상태에 따라 「이 노드 아래로 모으기」 또는 「새 상위 노드로 묶기」가 나타납니다. 그룹 박스와 달리 부모·자식 연결 관계를 바꿉니다.
연결선: 관계·화살표·경로·접점 18개 항목
🔗 연결 → 시작 → 대상선이 선택되지 않은 상태에서 「연결」을 누르고 시작 노드와 대상 노드를 차례로 클릭하면 참조선을 만듭니다. 참조선은 부모·자식 관계를 바꾸지 않는 추가 연결입니다.
노드 가장자리의 점연결 모드에서 표시되는 점을 누르면 선이 붙을 면이나 모서리를 지정할 수 있습니다. Esc 또는 「연결」 버튼으로 모드를 종료합니다.
설정창의 ⠿ 연결선 설정 드래그창 위쪽 제목을 끌어 화면을 가리지 않는 위치로 옮기세요. 설정창을 다시 열어도 옮긴 위치를 유지하고, 새로고침하면 기본 위치로 돌아갑니다.
선 교차의 둥근 우회 표시서로 연결되지 않은 선이 교차하면 한 선이 둥글게 넘어가는 표시가 자동으로 나타납니다. 연결된 끝점과 나란히 겹치는 구간은 우회 표시를 하지 않으며 실제 연결 관계와 저장된 경로는 유지됩니다.
연결선 클릭 / 우클릭선 설정 메뉴를 엽니다. 화살표 방향·선 모양·색상·접점 위치를 설정할 수 있습니다.
─ / → / ← / ↔화살표 없음 / 정방향 / 역방향 / 양방향을 선택합니다.
∿ / ┐ · ━ / ┄ / ═∿는 곡선, ┐는 모서리가 둥근 꺾은선입니다. ━ / ┄ / ═로 실선·점선·두줄 스타일을 고릅니다.
선 메뉴 → ＋ 중간 노드 추가두 노드를 잇는 선을 클릭하거나 우클릭한 뒤 「중간 노드 추가」를 누르세요. 선 가운데에 새 노드가 생기고 앞 노드 → 새 노드 → 뒤 노드로 연결됩니다. 이름을 입력한 뒤 Enter로 완료합니다. 부모·자식 선과 참조선 모두 지원하며 선 색상·스타일·화살표를 유지합니다. 같은 그룹의 두 노드 사이에 넣으면 새 노드도 그룹에 포함됩니다. 화면 위치와 배율은 유지되며 Ctrl+Z로 삽입을 되돌립니다.
선 메뉴의 🎨선 색상을 고릅니다. 팔레트의 ＋로 원하는 사용자 색상을 추가합니다.
선의 원형 조절점 드래그선에 마우스를 올려 나타나는 조절점을 끌면 굽힘이나 꺾임 위치를 바꿀 수 있습니다. 가까운 같은 축 선에 맞춰지는 경우도 있습니다.
주변 선을 이 선에 합치기기준이 될 꺾은선을 클릭한 뒤 이 버튼을 누르세요. 현재 화면에 있는 같은 색·스타일의 꺾은선 중, 지도 좌표에서 80 이내이고 30 이상 겹치는 공통 구간을 기준 선 위치로 맞춰 저장합니다. 노드 연결은 유지되고 Ctrl+Z로 되돌릴 수 있습니다.
중앙 노드 우클릭 → ≡ 연결선 정리직접 연결된 노드가 2개 이상인 중앙 노드를 우클릭하고 「연결선 정리」를 누르세요. 우클릭한 노드를 기준으로 연결된 노드를 왼쪽·오른쪽의 세로열로 배치하고 공통 세로선에 연결합니다. 기존 부모 관계·화살표 방향·선 색상과 스타일을 유지하며 위치와 경로를 저장합니다. Ctrl+Z로 배치와 선을 함께 복원할 수 있습니다.
공통선의 원형 손잡이 드래그연결선 정리 후 공통 세로선에 표시되는 원을 좌우로 끌면 같은 공통선에 붙은 가지선이 함께 따라옵니다. 잠금 상태에서는 먼저 잠금을 해제하세요. 개별 선의 접점 이동이나 곡선 전환을 사용하면 해당 선은 공통선에서 분리되어 개별 조정됩니다.
조절점 더블클릭해당 선의 경로 조정값을 초기화합니다.
선 메뉴 → 접점 이동「도착점」 또는 「출발점」을 선택한 뒤 ← / ↑ 또는 → / ↓를 누르세요. 노드 위·아랫면에서는 좌우로, 좌·우면에서는 상하로 10씩 이동합니다. 겹치는 선을 바로 옆으로 분리할 때 사용하세요.
접점 이동의 초기화선택한 출발점 또는 도착점의 수동 위치를 해제하고 자동 위치로 되돌립니다. 이동한 접점은 저장되며 Ctrl+Z로 되돌릴 수 있습니다.
선 선택 → 🔗 연결선의 양 끝 노드에 표시되는 점을 클릭해 연결면을 변경합니다.
🔀 / ✂️ / 🗑 / Delete부모·자식 선 메뉴의 🔀는 새 부모 선택, ✂️는 관계 끊기입니다. 참조선 메뉴의 🗑는 참조선을 삭제합니다. 선을 선택하고 Delete를 눌러도 연결을 끊을 수 있습니다.
그룹: 제목·크기·배경·이동 8개 항목
여러 노드 선택 → 📦 그룹빈 공간에서 Shift+드래그로 2개 이상 선택한 다음 「그룹」을 누르세요. 노드 위치를 유지한 채 둘레에 그룹 박스를 만듭니다.
그룹 제목 클릭그룹 설정 패널을 엽니다. 그룹 이름·색상·배경 표시를 바꿀 수 있습니다.
그룹 제목 더블클릭「폰트 크기」 가로 슬라이더가 나타납니다. 구슬을 왼쪽으로 움직이면 작아지고 오른쪽으로 움직이면 커집니다. 제목 크기는 바로 반영되어 저장됩니다.
그룹 테두리 크기 조절그룹 제목을 클릭한 뒤 테두리의 연두색 사각 손잡이를 끌어 크기를 줄이거나 늘리세요. 노드와 연결선은 이동하지 않으며 박스 비활성화 상태에서도 조절할 수 있습니다. 「테두리 자동」은 내부 노드에 맞는 크기로 복원합니다. 수동 크기는 저장되고 Ctrl+Z로 되돌릴 수 있습니다.
그룹 제목 드래그그룹에 포함된 노드와 내부 연결선의 수동 꺾임 위치를 함께 옮깁니다. 내부 선 모양을 유지하며, 외부 노드와 연결된 선은 외부 끝점을 유지하고 그룹 쪽 끝점이 따라옵니다. Ctrl+Z로 노드와 선을 함께 복원할 수 있습니다.
그룹 설정의 색상 / ＋그룹 제목과 박스 색상을 바꿉니다. ＋로 사용자 색상을 추가할 수 있습니다.
그룹 설정창의 ⠿ 📦 그룹 드래그설정창 왼쪽 위 제목을 끌어 원하는 위치로 옮기세요. 색상이나 이름을 바꿔도 옮긴 위치를 유지하며, 페이지를 새로고침하면 기본 위치로 돌아갑니다.
그룹 설정의 글자색 / 자동그룹 제목을 클릭한 뒤 「글자색」에서 색을 고르세요. 색상 선택창에서 움직이는 동안 제목에 실시간으로 반영됩니다. 「자동」은 배경색에 맞는 글자색으로 되돌립니다. 배경색·제목 크기와 별도로 설정됩니다.
그룹 설정의 🔲박스 배경을 비활성화하는 투명 표시를 전환합니다. 그룹 박스가 노드 클릭을 막으면 이 설정을 켜세요.
그룹의 × / 설정의 🗑그룹 박스를 삭제합니다. 그룹 안의 노드 자체는 삭제되지 않습니다.
메모·체크리스트·이미지 5개 항목
노드 선택 → M메모창을 열거나 닫습니다. 노드 우클릭 → 「메모 열기」로도 열 수 있습니다.
메모 입력노드별 설명·운전 참고사항 등을 적을 수 있습니다. 일반 작업 파일에서는 입력 내용이 자동 저장됩니다.
메모 서식 버튼체크박스·글머리·번호·들여쓰기·내어쓰기·구분선을 추가할 수 있습니다. 아래 미리보기에서 정리된 내용을 확인하세요.
📎 이미지 추가클릭해 이미지 파일을 고르거나 이미지 추가 영역에 파일을 끌어 놓으세요. 첨부 이미지의 ×로 삭제합니다.
이미지 클릭 / 노드에 마우스첨부 이미지를 클릭하면 크게 봅니다. 메모나 이미지가 있는 노드에 마우스를 올리면 미리보기가 나타납니다.
다른 카테고리로 복사·이동 5개 항목
Ctrl+C → 카테고리 전환 → Ctrl+V노드 또는 여러 노드를 선택해 복사하고, 대상 카테고리를 클릭한 뒤 붙여넣으세요. 하위 노드도 포함하며 원본은 유지됩니다.
노드 우클릭 → 다른 카테고리로 복사 / 이동대상 카테고리를 선택하고 「하위 노드도 함께 포함」 여부를 정한 뒤 「복사」 또는 「이동」을 누릅니다. 먼저 대상 카테고리를 만들어 두세요.
복사와 이동의 차이복사는 원본을 남기고, 이동은 원본 카테고리에서 제거합니다. 메모·이미지·포함된 노드 사이의 연결과 그룹 정보가 함께 전달됩니다.
붙여넣는 위치기본은 대상 지도 오른쪽 빈 공간입니다. 복사한 뒤 빈 공간 우클릭 → 「붙여넣기」로 클릭한 위치에 붙일 수도 있습니다.
Ctrl+Z복사·이동을 되돌릴 수 있습니다. 노드 복사 내용은 현재 열린 페이지 안에서 사용하며, 새로고침하면 다시 복사해야 합니다.
화면 보기·구슬·잠금·검색 8개 항목
빈 공간 드래그 / 마우스 휠빈 공간을 끌면 지도가 이동합니다. 휠은 확대·축소입니다. 상단 ＋ / － 버튼으로도 배율을 바꿉니다.
⊡ 맞춤현재 카테고리의 노드 전체가 화면에 들어오도록 배율과 위치를 맞춥니다.
🔵 구슬 ON / ⚪ 구슬 OFF연결선을 따라 움직이는 구슬을 켜거나 끕니다. ON일 때 선택 노드와 연결된 화살표 선에 표시됩니다. 설정은 다시 열어도 유지되며, 시스템의 동작 줄이기 설정이 켜져 있으면 구슬이 숨겨집니다.
🔒 잠금노드 드래그와 연결선 조정을 잠그거나 해제합니다. 배치 작업 전에 잠금 상태를 확인하세요.
Ctrl+F → 검색어 입력현재 카테고리의 노드 이름을 검색합니다. Enter는 다음 결과, Shift+Enter는 이전 결과, Esc는 검색창 닫기입니다.
☀️ 라이트 / 🌙 다크화면의 밝은 테마와 어두운 테마를 전환합니다.
🎨 색상설정부모에서 하위 노드로 내려갈수록 색이 얼마나 연해지는지와 적용 깊이를 설정합니다. 미리보기 후 「적용」을 누르세요.
새 하위 노드 방향하위 노드 옆의 방향 메뉴에서 자동·오른쪽·왼쪽·아래·위를 고릅니다. 이후 생성하는 하위 노드에 적용됩니다.
저장·백업·복원·초기화 6개 항목
일반 작업 파일의 자동 저장지도 데이터는 현재 브라우저의 저장소에, 이미지는 별도 이미지 저장소에 보관됩니다. 다른 브라우저나 PC에는 자동으로 전달되지 않습니다.
💾 백업 → JSON 내보내기카테고리·노드·메모·이미지를 포함한 데이터 백업 파일을 만듭니다. 나중에 「불러오기」로 복원할 때 사용합니다.
💾 백업 → JSON 불러오기JSON 백업을 선택해 복원합니다. 현재 데이터 전체를 교체하므로 필요하면 먼저 현재 작업을 내보내세요.
💾 백업 → HTML 내보내기지도 데이터와 이미지를 넣은 HTML 파일을 만듭니다. 이 파일은 직접 열어 볼 수 있는 별도 백업본입니다.
내보낸 HTML에서 수정한 경우원본 브라우저 데이터를 덮어쓰지 않도록 자동 저장하지 않습니다. 변경 내용을 보관하려면 수정 후 다시 내보내세요.
🗑 초기화현재 카테고리의 지도를 중심 주제 하나로 초기화합니다. 다른 카테고리는 유지됩니다. 실행 전 필요한 내용을 백업하세요.
자주 쓰는 단축키 한눈에 보기 6개 항목
Tab / Enter / F2하위 노드 추가 / 같은 단계 노드 추가 / 노드 이름 편집. 먼저 노드를 선택하세요.
Ctrl+C / Ctrl+V선택 노드와 하위 노드 복사 / 현재 카테고리에 붙여넣기.
Ctrl+Z삭제·드래그·선 조정·카테고리 복사/이동 등 되돌리기가 지원되는 작업을 복구합니다. 모든 설정 변경에 적용되는 것은 아니며, 페이지를 다시 열면 이력은 사라집니다.
Ctrl+B / Ctrl+U / S / M선택 노드의 굵게 / 밑줄 / 중요 표시 / 메모창 열기·닫기.
Ctrl+F / ? / Esc노드 검색 / 도움말 열기 / 현재 편집·선택·연결 모드에서 빠져나오기.
문자 입력 중에는노드 이름·메모·검색창 등에 입력 중이면 해당 입력칸의 동작이 우선합니다. 노드 이름의 줄바꿈은 Alt+Enter입니다.
